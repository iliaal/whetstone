# Evaluating Agent Interventions

Use this procedure to measure whether a hook, prompt rule, or skill changes task outcomes. Produce an experiment report containing the registered hypothesis, arm results, invalid trials, paired effect analysis, noise controls, and cost.

1. **Register the decision before the main run.** State the hypothesis, outcome rubric, primary comparison, analysis method, and sample size justified by a pilot. Freeze the scenarios and stopping rule. Do not extend the run after inspecting significance. Declare the run inconclusive if more than 10% of trials are invalid; classify invalidity without reference to whether the intervention won.
2. **Separate the content from the interruption.** Run three arms: `off` without the intervention, `gate` with its full content, and `placebo` with the same interruption but without the targeted instruction. Keep models, tool access, budgets, and initial state comparable. Randomize execution order and isolate each trial's state.
3. **Build discriminating scenarios.** For a question-asking intervention, put one decisive fact outside the repository and tools, behind a simulated user that reveals it only when asked. Give every arm the same access to that user. Derive the task and acceptance criteria independently of the intervention's vocabulary. State any output format required by the grader in the task prompt. An all-arms-perfect result indicates a ceiling that cannot establish this intervention's benefit; redesign the scenario rather than declaring a null effect.
4. **Pair outcomes and preserve controls.** Pair each arm by scenario and repetition. Include a scenario the intervention cannot influence as a run-to-run noise control. Record paired pass/fail results and invalid-trial reasons, not just aggregate pass counts. A gain caused by the baseline deteriorating, or a treated change no larger than control drift, does not establish a stable benefit.
5. **Use the registered paired analysis.** For independent pairs with binary outcomes, use an exact McNemar test on discordant pairs; [statsmodels documents the binomial exact calculation](https://www.statsmodels.org/stable/generated/statsmodels.stats.contingency_tables.mcnemar.html). Report the paired effect and uncertainty as well. If a bootstrap interval and the registered exact test disagree, retain the exact test as the primary decision and disclose the disagreement. Do not select whichever analysis looks favorable. Account for dependent repetitions or scenario clusters in the experimental design instead of treating correlated trials as independent evidence.
6. **Report the cost of the effect.** Show turns, tokens, and spend beside outcome changes for all three arms. Distinguish an inconclusive experiment from evidence of no useful effect. Retain failures and noise-control results even when cost is the only stable measurement.

Complete the evaluation only when every registered trial has a disposition and the report follows the original decision rule. Do not promote an intervention using grader checks that merely repeat its instructions, saturated fixtures, or a sample enlarged after seeing the result.
